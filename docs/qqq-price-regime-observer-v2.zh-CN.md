# QQQ 价格状态观察信号 V2

状态：`DESIGN_ONLY_NOT_RUNTIME`

这是给未来 TQQQ 观察候选使用的纯确定性信号生产器。它从调用方已验证的 QQQ
日线收盘价序列，计算截至同一 `as_of` 的事实：收盘价相对 200 会话均线、5 与 252
会话年化已实现波动率、以及 252 会话回撤。它不读取文件、行情服务、GCS、账户或凭证。

输出必须由调用方封装为 `qsl.strategy-plugin-signal.v2`，其中 P1 manifest、input-root
hash 和 cutoff 均与观察结果精确绑定。生产器配置也是固定、可 hash 的：QQQ、200 会话
趋势、5/252 会话波动率、252 会话回撤和 252 年化因子；未知字段一律拒绝。

该信号只表达事实与原因码，不含也不能表达仓位、交易、账户、资金、执行控制或授权。
它不会改变当前 `tqqq_core_only_p2_v5` 的目标，也不会使 v6 成为日更候选。下一步必须由
UESP 的 P3 在已验证 P1 根上独立重算此信号并证明信号与 v5 目标相同，之后才能开始积累
前瞻观察记录。
